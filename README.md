# Dormis Backend 🏢

**Dormis** — backend частина інформаційної системи автоматизації адміністративно-побутової діяльності гуртожитків.

Проєкт розробляється як дипломна робота та орієнтований на вирішення реальних проблем управління гуртожитками: заселення, комунікація, безпека, заявки та облік ресурсів.

---

## 🎯 Мета проєкту

Створити масштабовану REST API систему на стеку **MERN**, яка забезпечує:

- безпечну авторизацію користувачів
- підтримку декількох гуртожитків (multi-tenant)
- гнучку систему ролей (RBAC)
- автоматизацію адміністративних та побутових процесів
